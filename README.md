# Attention Is All You Need：重要性 · 表达 · 理解 · 处境

一个关于 Vaswani 等人 2017 年论文《Attention Is All You Need》的中文交互式网站项目。

论点：这篇论文属于人类史上最伟大的那一类作品。它带来的是**断层式**的变化，而它的重要性目前被严重低估了，因为人们对 AI 带来的冲击还没有做好准备。

组织方式依照怀特海《Modes of Thought》（1938）前三讲的顺序：**先有重要性的感受，再有表达，然后才是理解**。

| 乐章 | 内容 |
|---|---|
| 序章 | 为什么是这个顺序 |
| 一 · 重要性 | 断层；和《原理》《物种起源》、狭义相对论并列；和最伟大的工程发明并列；中心悖论 |
| 二 · 表达 | 生成史（2016 年成型、2017 年春爆发）；把它当工程文本来读；读书会指南 |
| 三 · 理解 | 拆零件；我们弄懂了什么、还没弄懂什么 |
| 四 · 处境与行动 | 为什么被低估；互联网和电力的滞后；过渡期的不对称优势；行动不是投资 |

## 仓库结构

- `PLAN.md`：已批准的项目规划
- `research/`：研究底稿。每条事实都带出处和证据标记
  - `cases.md`：历史案例库，包括互联网、电力、蒸汽、印刷术、集装箱、Google、柯达与富士等
  - `great-works.md`：《原理》《物种起源》、狭义相对论、Transformer 四篇并列，以及各项发明以什么形态进入世界
  - `genesis.md`：生成史。从约 2014 年的想法、2016 年成型到 2017 年春爆发；贡献脚注；作者的去向
- `site/index.html`：网站。单页静态 HTML，不需要构建；当前是 M1 预览版
- `experiments/`：小规模 Transformer 实验，在 M4 阶段做

## 证据标记

- **[V]**：已对照一手或权威来源核实
- **[S]**：只有二手来源
- **[NV]**：未能核实，不进正文
